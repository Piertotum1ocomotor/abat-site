# Steel Blue Corporate

Согласованное визуальное направление сайта компании «Абат».

## Основные правила

- светлый корпоративный интерфейс;
- стальной синий — основной фирменный цвет;
- оранжевый — только CTA и небольшие акценты;
- Manrope — единственный шрифт;
- 12-колоночная сетка на desktop;
- один столбец на мобильных;
- минимум теней;
- тонкие границы;
- реальные фотографии объектов и производства;
- не более одной визуально главной CTA в одном блоке;
- обязательные hover и focus-состояния;
- только один H1 на странице.

Значения во frontmatter являются источником истины. Новые цвета,
радиусы и размеры не добавляются в компоненты без обновления этого файла.
